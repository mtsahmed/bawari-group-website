# Brand Assets Drop Folder

Drop raw client-provided files here and just tell me what to do with them (e.g. "use logos/logo.svg as the site header logo").

- `logos/` — logo files (SVG preferred, PNG also fine)
- `images/` — photos, illustrations, screenshots for case studies etc.
- `documents/` — PDFs, brand guideline docs, copy decks, etc.

This folder isn't tracked in git (see `.gitignore`) — it's a staging area. Once a file is actually used on the site, I'll copy/process it into `public/` or the relevant component so it becomes part of the tracked project.
